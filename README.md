# 📊 Zaawansowane Struktury Danych

## 🔗 Link do repozytorium z aplikacją demonstracyjną
➡️ [Zobacz kod źródłowy projektu Java](https://github.com/mataleksander03/ClientManager)

## 🏋️‍♂️ Zadania:
- 1.łatwe / tablice
- 2.łatwe / stosy
- 3.sredniotrudne/ kopiec
- 4.srednie/ hashmapy
- 5.średnie/ mapy i kolejki


## 🛠️ Technologie aplikacji
- JavaFX (interfejs graficzny)
- Struktury danych: `TreeMap`, `HashMap`, `Set`, `List`
- Maven (do zarządzania projektem)

## 🧪 Praktyczne możliwości aplikacji
- Filtrowanie zamówień według:
  - Zakresu cen (z użyciem `TreeMap`)
  - SKU produktu (`HashMap`)
  - Imienia i nazwiska klienta (`HashMap` + `Set`)
- Obsługa złożonych zapytań (łączenie filtrów)
- Obliczanie czasu filtracji

## 🖼️ Prezentacja
Do projektu dołączona jest prezentacja opisująca:
- Historię struktur danych
- Rodzaje struktur (m.in. drzewa, kopce, grafy, filtry Blooma)
- Przykłady praktyczne i porównania złożoności
- Struktury przyszłości (np. homomorficzne, AI-friendly)
